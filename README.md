# Aplikasi Pelayanan Dinas Sosial — V1

Aplikasi web sederhana untuk belajar HTML, CSS, JavaScript, dan GitHub Pages.

## Fitur
- Dashboard jumlah data
- Input data pelayanan
- Status Menunggu / Diproses / Selesai
- Pencarian data
- Filter status
- Hapus data
- Hapus semua data
- Export CSV
- Penyimpanan lokal browser menggunakan localStorage
- Responsif untuk desktop dan HP

## Menjalankan di komputer
Buka file `index.html` menggunakan browser.

## Upload ke GitHub
1. Buat repository baru di GitHub.
2. Upload `index.html`, `style.css`, dan `script.js`.
3. Masuk ke **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Simpan.
7. GitHub akan memberikan alamat website.

## Catatan penting
Versi ini adalah aplikasi pembelajaran dan **belum cocok untuk menyimpan data pribadi masyarakat secara nyata**, khususnya NIK, karena data hanya tersimpan di browser masing-masing perangkat.

Untuk penggunaan resmi, tahap berikutnya sebaiknya memakai login, database/server, hak akses, audit log, backup, dan perlindungan data pribadi.
